-   UI/UX・文言・アクセシビリティ上の問題を発見する。

## 4. Issue評価基準

### Severity

-   Critical：データ消失、安全・プライバシー上の重大問題、主要機能が利用不能
-   High：主要タスクを完了できない／重大な誤解につながる
-   Medium：回避可能だが操作負担・理解を大きく損なう
-   Low：軽微な表示・文言・操作改善

### Priority

Severityだけでなく、発生頻度、利用者影響、修正コスト、公開への影響を合わせて決定する。
