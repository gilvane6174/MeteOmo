# 第1部　アプリ設計図

## 1. 目的

天候と気圧を表示し、ユーザーが入力した服薬情報と、うつ症状を含む気分を記録・管理・分析できるようにする、メンタルヘルス支援プラットフォームの構想です。

- 記録はユーザー自身が管理・分析できる
- 将来的には、ユーザーの任意で、匿名データをうつ病治療薬の研究開発機関へ提供できるようにする
- 将来的には、ユーザーの任意で、国内外の教育機関への支援にもつなげる

## 2. メイン機能

※全体として、ユーザーに負担のない軽量で快適なUIにする。

### 2-1. 天気・気圧データの取得・表示（トップ画面「気分」タブ内）

- OpenWeatherMap API を使用し、GPSで地域を自動特定
- 天気・気圧・気温・湿度を表示
- 毎日記録された気分と天気・気圧の重なりをグラフ表示（Dart charts_flutter）。トップから「過去ログ」へ遷移して表示

### 2-2. 気分（うつ症状）ログ（トップ画面「気分」タブ内、天候マークの下）

- 1日3回（朝・昼・夜）の記録プロンプト
  - 1日1回の入力でも可
  - アプリを開かなかった日も、その事実を自動記録
  - 1日のうち何時頃に何回入力されたかを記録
- 記録内容
  - 3段階の顔アイコン（良い・普通・悪い）をタップ
  - または「気分詳細」アイコンから、ハッシュタグ（既存・ユーザー追加）を選ぶか、自由記述メモを記録
- 記録した瞬間に短い効果音が鳴り、画面がわずかに光る（設定で消音・発光停止が可能）→ 自動で服薬ページへ遷移
- 効果音の種類を選べるUIを用意し、満足度を上げる
- 週1回、服薬入力後に任意のPHQ-9チェックをポップアップ表示
  - 入力せず閉じるボタンあり／設定から常に非表示にできる／回答は記録
  - 将来的にPHQ-9以外の簡易指標（例：GAD-7）も選択肢に追加

### 2-3. 服薬・サプリ・食事のログ（トップから自動遷移／「服薬」タブ切り替えで遷移）

- 登録項目
  - 薬名（ユーザー入力。薬名から正式名称を候補表示して選択可能。錠数と服用時刻を事前登録、時刻は複数可）／過去の履歴から選択／後から詳細編集
  - 服薬がないユーザーには「服薬なし」とだけ表示
  - 飲んだ時間
  - 効果（体感ベース）
  - 副作用（任意選択）
- 相関分析
  - グラフ比較（薬×気分）
  - GPTによる傾向サマリー（例：「最近、この薬とこの気圧のときに気分が安定しています」）。診断として機能しないよう制御する
- 薬一覧を一度登録すると、服用時刻ごとにまとめて表示
  - 例：7時「薬A」「薬B」飲んだ？／12時「薬B」／22時「薬C」「薬D」
  - 左の「飲んだ」ボタンを押すと、GPT連携で短い声かけ（例：「飲めたね」）をポップアップ表示・記録
  - その後「今飲んだ薬一覧」画面へ遷移し、飲んだ薬をすぐ再確認できる
- トップへ戻るときはタブ切り替え

### 2-4. AIによる予想・サポート（後から追加／GPT連携を許可したユーザーのみ）

- トップ画面最下部の「お喋り」ボタンから任意で遷移
- GPT-4 Turbo との会話API連携（作成当時の想定モデル）
- 「おはよう」から「寝る前」までの短い声かけ会話（プロンプトベース）
- 天気・気圧・薬データを内部参照して、今日のアドバイスを提示
  - 例：「今日は気圧が低くて寒いです。天気は曇り。厚着をして変化に気を付けた方が良いかもしれません」
- 簡易予想
  - 例：「明日は雨。気圧が急降下します。ご注意ください」
- GPTの応答はアプリ側で受け取るだけで、データベースには保存しない（情報管理リスクの回避）

### 2-5. PDF出力

- 記録を医師に見せられるPDFを出力する
- 目的：「一人で抱え込まないでください」というリマインドと合わせて、孤立を防ぎ支援につなげる
- 保存先はスマホ本体のローカルストレージのみ（情報管理リスクの回避）
  - Android：`/Downloads/MeteOmo/`（パーミッション要確認）
  - iOS：Files 内のアプリディレクトリ（保存先をユーザーに通知）
- セキュリティ対策
  - 保存時に「この記録には個人情報が含まれる可能性があります」と確認表示
  - アプリ内でPDFを削除できる
  - ファイル名は日付＋乱数（例：`meteomo_log_20250621_3f82.pdf`）

### 2-6. 支援への導線

- 設定画面に「誰かと話したいとき」を用意
- いのちの電話・全国保健所検索などの連絡先を表示
- 「これは緊急連絡ではありません」という誤解防止文を表示

### 2-7. データ連携と統計（後から追加）

- 匿名IDベースで記録データを研究機関と共有し、治験に協力できる仕組み（ユーザーの同意が必須）
- アプリ内で「あなたと同じ傾向の人：何人」などの集計を表示

### 2-8. 教育施設への支援（後から追加／ユーザーの任意）

- 国内機関や発展途上国への募金（信頼できる候補を事前に選定／寄付先は要選定）
- 目的：ユーザーが社会に関わる機会をつくり、自己肯定感を高める

## 3. 追記

- ユーザーの入力内容から、ストレスや不調の加算・減算でメンタル状態を数値化する
  - 医師に見せる印刷用PDFや、本人による状態の可視化に使う
  - 年金などの制度手続きで使われる可能性も考え、悪用の予防策を講じる
- ローディング画面、エラー時のお詫び画面、「通信中」表示を入れる（遅延時のストレス軽減）

## 4. アクセシビリティ・マルチユーザー対応

- 設定画面からダークモードに切り替えられる
- 文字サイズは端末設定に従う
- 視覚・聴覚支援に対応（例：読み上げ、バイブ通知）
- 複数ユーザー用のログイン機能は現時点では搭載しない。後から実装できるよう別モジュールにしておく

## 5. 医療との連携（将来への備え）

- PDF出力フォーマットを医療現場で扱いやすくする
  - 日付順、気分・服薬・副作用をセットで表示
- 医療従事者向けのビュー（後から追加）
  - 閲覧専用（診断はせず「確認のみ」。下記の注意書きをPDF内に入れる）

# 第2部　フローチャート

## 1. トップ画面

```text
[トップ画面]
  ├─ アイコン・アプリ名表示
  ├─ 「気分」「服薬」切り替えタブ表示
  ├─ 「天候」「気圧」等表示 ⇒ アイコンタップで詳細・過去1週間分の天候や気圧等を表示
  ├─ 「今日の気分は？」文字表示
  ├─ 気分アイコン①②③タップ ⇒ アニメーション（光・浮き） ⇒ 気分記録＋即時保存
  └─ ペン先アイコンタップ ⇒ 「詳細気分記録画面」へ
```

## 2. 気分記録

```text
トップ画面（MeteOmo）
   ↓
「気分」記録タブ（デフォルト選択）
   ↓
顔アイコンタップ（良い・普通・悪い） → 自動記録（＋光る演出）
   ※押し間違えた時用に「今日の気分修正」ボタンをページ下に小さく配置
   ↓
顔アイコン横のペンアイコン → 詳細記入ページ
   ├─ テキスト＋用意済みのハッシュタグから選択
   ├─ 「＋」でハッシュタグを追加できる。DBに登録し次回以降も表示（全体で15個まで）
   └─ 「保存」 → GPT連携 or ローカル保存 → 保存後、自動で「服薬」タブに切り替え

トップページ最下部に「気圧と体調の連動」ボタン
   └─ 過去7日 or 30日のグラフで「気圧×気分×薬」を重ねて可視化
      （初期は空。1日分のデータが増えるごとに自動追加。7日／30日はページ上部のタブで切り替え）
```

## 3. 服薬

```text
「服薬」タブに切り替え（タブ強調）
   ↓
服薬メイン画面
   ├─ [＋薬を登録]
   │     ├─ 薬名（自由記述 or DB検索）
   │     ├─ 市販薬チェック欄
   │     └─ 朝・昼・夜・就寝前の4枠に登録 → 保存 → 一覧に追加
   ↓
登録済み薬一覧（朝・昼・夜・就寝前の4枠を1画面で表示）
   ├─ 例：朝の「飲んだ」ボタン → 「全て飲みましたか？」ポップアップ「OK」「NO」
   ├─ 「NO」→ ポップアップが消え元の画面へ
   ├─ 「OK」→ チェックマーク表示＋「できたね！」と表示、数秒後に元の画面へ
   └─ 薬の詳細ボタン → 効能・副作用・注意情報、端に削除ボタン
         ├─ 削除ボタン → 「本当に消していいの？」ポップアップ
         ├─ 「OK」→ 削除
         └─ 「NO」→ 元の画面へ

[薬ごとの感想記録]
   ├─ 「飲んだあとどうだった？」→ 記入欄 or 用意済みハッシュタグを選択 → 「保存」
   └─ 「＋」でハッシュタグを追加できる。DBに登録し次回以降も表示（全体で15個まで）
```

## 4. 設定画面

```text
「設定」画面
   ├─ GPT連携の許可（トグル）＋「詳細説明を見る」「OpenAI API利用に関するポリシー」
   │    「自動保存・暗号化保存選択」の各ページへ。各ページに「戻る」ボタン
   │    （GPT連携ON時は、送信時に「AIに送信しました」と小さく表示して透明性を確保）
   ├─ 治験提供の同意・変更
   ├─ カスタマイズ：通知・色・文字・音
   └─ PDFで書き出す：「薬一覧」「気分一覧」の2種類から選択
         ├─ 「薬一覧」：市販薬も含め、登録済みの薬を時間順に記載して出力
         └─ 「気分一覧」：1日／1週間／1か月／3か月／半年／1年から選択
              出力内容：日時（選択期間）／気分評価／詳細記述／服薬状況
              （薬の詳細は書かず、飲めているかどうかのみ）／感想
              医師に見せやすいよう、簡潔で長くなりすぎない形式
```

### 動作モード（ユーザー設定で選択）

| モード | 内容 |
|---|---|
| 安全モード | 自動削除あり／PDFはセッション中のみ一時生成（保存なし） |
| 研究モード | 暗号化保存／PDF出力も選べる／削除は手動または定期的な確認通知 |

# 第3部　補足

## 1. 自己診断への依存を避けるための設計指針

ユーザーが自己判断だけに頼らず、支援につながれるようにする。

- 「通院中の方へ」などの注意書きをアプリ内に明記する
- 「この記録を医師に見せられます」機能で、記録をPDF等で出力できるようにする
- 定期的に「一人で抱え込まないでください」というメッセージを表示し、支援への導線を保つ

説明文には次の一文を太字で入れる。

> **このアプリは「心の天気予報士」としての役割に徹し、医療や治療の代替にはなりません。**

## 2. 説明文（App審査向け）

> 本アプリ「MeteOmo」は、あなたの気分と服薬記録を支える“心の天気予報士”です。
> 医療や治療を代替するものではありません。体調に不安がある場合は、専門機関へのご相談をおすすめします。
>
> 「記録を医師に見せられるPDF出力機能」や「一人で抱え込まないでください」というリマインドを通じて、孤立を防ぎ、支援への接続を促進することを目的としています。また、ユーザーの任意でデータを治験機関等に提供し、将来の薬の開発に役立てることを検討しています。

- 将来、協力企業が決まったら「このデータを提出しますか？」という説明文を追加する
- 現時点の表記は「提出する可能性があります（未定）」とする

## 3. 初回起動時のポップアップ文案（確認・同意形式）

> **【AI連携についてのご案内】**
> 本アプリ「MeteOmo」では、ユーザーが入力した「気分の詳細」や「選択したタグ」などの情報を、あなたの同意がある場合のみ、OpenAI の AI（GPT）に送信します。
> これは、あなたに合った言葉や声かけを届けるために行われます。
>
> 安心ポイント：
> - 送信は、あなたが操作したときだけです
> - OpenAI API 経由の情報は学習に利用されません（※作成当時の公式説明に基づく。公開前に最新の規約で要確認）
> - データは外部のクラウドサーバーには保存されません
> - GPTへの送信以外の同期は一切行いません
>
> この設定は後から「設定画面」でも変更できます。
>
> [同意して使う]　[使わない（後で設定可）]

## 4. 設定画面に常設する説明（再確認用）

> **【GPT連携の目的と安全性】**
> 本アプリでは、あなたの「気分の詳細記録」をもとに、より自然で寄り添うメッセージを届けるため、OpenAI 社の AI（GPT）との連携機能を搭載しています。
> この機能をONにすると、入力した内容がその都度、匿名でGPTへ送信されます。
>
> - 送信された内容は学習に使われません（※作成当時の公式説明に基づく。公開前に要確認）
> - GPTに送信された内容は、アプリ内にもサーバーにも保存されません
> - 送信は、あなたが「保存」ボタンを押したときだけです
>
> この機能はいつでもOFFにできます。

## 5. PDF印刷時のセキュリティ

印刷そのものはリスクにならないが、次の点に配慮する。

- 印刷用PDFは端末内に一時生成し、一定時間後に自動削除（例：10分）
- 「PDFを出力したあと保存されていません。保存したい場合はご自身で端末内に保存してください」と表示
- クラウド連携はオフがデフォルト（ユーザーが許可すればオン）
- ユーザー保護モード（安全モード）の案
  - 一時ファイルは暗号化されたテンポラリディレクトリにのみ作成
  - 印刷後はキャッシュを自動削除（Flutterでも実装可能）
  - 他人に見られないよう、出力前に顔認証やPIN確認のオプション

## 6. 一人で作るためのロードマップ（分割設計）

| 段階 | 内容 |
|---|---|
| 第一段階：ローカル完結・完全オフライン | Flutter＋SQLite or Hive でローカル保存／GPT連携なし（設定画面にトグルだけ用意）／データは一切外に出さない／表示と記録まわりの完成を目指す |
| 第二段階：GPT連携追加（クラウド同期はしない） | ユーザーが「GPT連携をON」にした場合のみ、気分記録を匿名でAPI送信／保存は引き続きローカル／GPTの応答は受け取るだけでDBに保存しない |
| 第三段階：希望者向けのCSV／PDF化と外部提出 | 医師に見せるPDF出力／将来、協力企業が決まったら「このデータを提出しますか？」の説明を追加（現時点は「提出する可能性があります（未定）」） |

### 同期の方針

同期は「GPT連携」に限定する。

- GPTに送るもの：気分の詳細（テキストのみ）、日時（任意）
- GPTから返るもの：声かけの調整用フィードバック（例：「今日は落ち込んでるみたいだね。無理しなくていいよ」）
- 送信タイミング：「詳細記入」画面で「保存」を押したとき、かつ設定で「GPTと連携する」がONの場合のみ
- OpenAI API経由。APIキーはローカルに保持し、クラウドDBは使わない
