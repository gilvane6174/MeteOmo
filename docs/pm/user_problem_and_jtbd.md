## 1. Problem Statement

気分や体調に波がある人は、診察や振り返りの時点で、過去数週間の状態・服薬・天候・生活上の変化を正確に思い出して説明することが難しい場合がある。

一方で、詳細な記録を毎日続けること自体が負担になることもある。

MeteOmoは、必要最低限の操作で日常記録を残し、必要な時に本人がまとめて振り返れる状態を作ることを目指す。

## 2. 想定利用者

-   気分の波を簡単に記録したい人
-   天気・気圧と自分の状態を同じ期間で見たい人
-   服薬した事実・時刻を残したい人
-   通院時に一定期間の経過を説明したい人
-   毎日の詳細入力を負担に感じる人

## 3. JTBD

### Job 1

「体調が変化した時、後から思い出せるように、その時の状態を短時間で残したい。」

### Job 2

「診察等で最近の状態を聞かれた時、記憶だけに頼らず自分の記録を見ながら説明したい。」

### Job 3

「気分・服薬・気象情報を別々に探すのではなく、同じ期間で見比べたい。」

### Job 4

「体調が悪く記録できない日があっても、失敗扱いされず自分のペースで使いたい。」

### Job 5

「自分の個人的な記録について、いつ・何を共有するかを自分で決めたい。」

## 4. User Need → Product Response

  User Need                    MeteOmoの対応
  ---------------------------- ------------------------------------------
  短時間で残したい             3段階を基本とする気分記録、詳細は任意
  日内変化も残したい           同日複数回記録
  服薬予定と実績を区別したい   予定時刻と実際の服薬記録を分離
  気象と状態を見比べたい       同期間の履歴・グラフ
  診察等で説明したい           PDF出力
  記録を強制されたくない       連続記録評価・未記録警告を原則採用しない
  データを自分で管理したい     ローカル保存、本人操作による削除・共有

## 5. 未検証の仮説

以下は現時点でユーザー調査による十分な検証結果が公開資料上ないため、仮説として扱う。

-   3段階の気分記録が最も負担が少ないか。
-   PDFが実際の診察で読みやすい形式か。
-   天気・気圧表示が利用者の振り返りにどの程度役立つか。
-   通知をどの程度必要とするか。
-   支援情報への導線がどの場面で必要か。
